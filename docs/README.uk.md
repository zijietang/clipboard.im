# Clipboard.im

### До іншого пристрою — лише одне посилання.

Clipboard.im — легкий онлайн-буфер обміну для передавання тексту, посилань і файлів між пристроями. Вставте на комп’ютері, відкрийте на телефоні або поділіться з іншою людиною. Усе працює в браузері, без реєстрації та встановлення застосунку.

## Для невеликих щоденних передавань

- **Починайте одразу.** Не потрібні обліковий запис, вхід, застосунок чи розширення браузера.
- **Одна адреса, різні пристрої.** Відкрийте ту саму адресу на телефоні, планшеті або комп’ютері. Змініть назву, щоб легше запам’ятати.
- **Текст і файли разом.** Вставляйте нотатки й посилання, перетягуйте файли, а потім копіюйте чи завантажуйте на іншому пристрої.
- **Скануйте й продовжуйте.** QR-код відкриває буфер на телефоні без введення адреси.
- **Виберіть спосіб доступу.** Установіть пароль або створіть посилання лише для читання. Одержувачі можуть переглядати й завантажувати, але не редагувати чи видаляти. Посилання може мати окремий пароль, а доступ можна скасувати.
- **Зручний вигляд.** Адаптивний інтерфейс, світла й темна теми та 22 мови.

## Коли стане в пригоді

Передати посилання з телефона на ноутбук. Надіслати документ на спільний комп’ютер для друку. Поділитися нотатками зустрічі та вкладеннями з колегою лише для читання.

## Три кроки для початку

1. Відкрийте сайт і отримайте адресу буфера обміну.
2. Вставте текст або завантажте файли. Клацніть поза текстовим полем, щоб зберегти зміни.
3. Відкрийте ту саму адресу на іншому пристрої або скануйте QR-код. Скопіюйте текст чи завантажте файли.

## Як це виглядає

Знімки справжнього сайту з демонстраційним вмістом від 18 жовтня 2026 року. Мобільне зображення використовує вікно браузера розміром з екран телефона. Мова інтерфейсу на зображеннях — англійська.

## Обмеження й доступ

Зараз сайт зазначає **100 МБ на файл**, **300 МБ на буфер обміну** та автоматичне очищення файлів через **7 днів**. Поточні обмеження дивіться в області завантаження. Зберігайте важливі файли окремо: сервіс призначений для тимчасового передавання.

Без пароля кожен, хто знає адресу, може отримати доступ і змінити вміст. Для перегляду та завантаження використовуйте посилання лише для читання. Зберігайте пароль доступу в таємниці.
