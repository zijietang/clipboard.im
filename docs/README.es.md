# Clipboard.im

### Tu próximo dispositivo está a un enlace de distancia.

Clipboard.im es un portapapeles online ligero para pasar texto, enlaces y archivos entre dispositivos. Pega en el ordenador, abre en el móvil o comparte con otra persona: todo desde el navegador, sin registrarte ni instalar una aplicación.

## Para esos pequeños envíos del día a día

- **Empieza al instante.** Sin cuenta, inicio de sesión, aplicaciones ni extensiones.
- **Un enlace para varios dispositivos.** Abre la misma dirección en el móvil, la tableta o el ordenador. Personalízala para recordarla mejor.
- **Texto y archivos juntos.** Pega notas o enlaces, arrastra archivos y cópialos o descárgalos en otro dispositivo.
- **Escanea y continúa.** Abre el portapapeles en el móvil con su código QR.
- **Elige cómo compartir.** Protege el portapapeles con contraseña o crea un enlace de solo lectura para ver y descargar sin editar ni borrar. Ese enlace admite una contraseña independiente y se puede revocar.
- **A tu manera.** Diseño adaptable, temas claro y oscuro e interfaz en 22 idiomas.

## Cuándo resulta útil

Pasar un enlace del móvil al portátil. Llevar un documento a un ordenador compartido para imprimirlo. Compartir notas de una reunión y archivos con un compañero mediante un enlace de solo lectura.

## Empieza en tres pasos

1. Abre la web para obtener una dirección de portapapeles.
2. Pega texto o sube archivos. Haz clic fuera del campo de texto para guardar los cambios.
3. Abre la misma dirección en otro dispositivo o escanea el código QR. Copia el texto o descarga los archivos.

## Límites y acceso

La web indica actualmente **100 MB por archivo**, **300 MB por portapapeles** y limpieza automática de archivos tras **7 días**. Consulta los límites vigentes en el área de subida. Conserva una copia de los archivos importantes: es una herramienta de transferencia temporal.

Sin contraseña, cualquiera que conozca la dirección puede acceder y modificar el contenido. Usa un enlace de solo lectura para permitir únicamente ver y descargar. La contraseña controla el acceso; mantenla privada.
