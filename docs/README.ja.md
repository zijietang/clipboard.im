# Clipboard.im

### 次のデバイスへ、リンクひとつで。

Clipboard.im は、デバイス間でテキスト、リンク、ファイルを受け渡すための軽量なオンラインクリップボードです。パソコンで貼り付けて、スマートフォンで開く。自分用の一時的な受け渡しにも、誰かとの共有にも。登録、ログイン、アプリのインストールは不要です。

## ちょっとした受け渡しを、もっと手軽に

- **すぐに使える。** アカウントもアプリもブラウザ拡張機能も不要です。
- **同じ URL でアクセス。** スマートフォン、タブレット、パソコンで同じクリップボードを開けます。覚えやすい名前にも変更できます。
- **テキストとファイルを一緒に。** メモやリンクを貼り付け、ファイルをドラッグして、別の端末でコピーやダウンロード。
- **QR コードで開く。** スマートフォンで読み取れば、URL の入力を省けます。
- **共有方法を選べる。** クリップボードのパスワードや閲覧専用リンクを設定できます。閲覧専用なら編集・削除はできません。共有リンクには別のパスワードを設定でき、共有も停止できます。
- **使いやすい表示。** モバイル対応、ライト・ダークテーマ、22 言語のインターフェース。

## こんなときに便利

スマートフォンのリンクをパソコンへ送る。共有パソコンで印刷するために書類を渡す。会議メモと添付ファイルを閲覧専用リンクで同僚に共有する。

## 使い方は 3 ステップ

1. サイトを開き、クリップボードの URL を取得します。
2. テキストを貼り付けるか、ファイルをアップロードします。テキストは入力欄の外をクリックすると保存されます。
3. 別の端末で同じ URL を開くか QR コードを読み取り、コピーまたはダウンロードします。

## 容量・保存期間・アクセス

現在の表示は **1 ファイル 100 MB**、**クリップボード全体で 300 MB**、ファイルは **7 日後に自動削除**です。最新の制限はアップロード欄をご確認ください。一時的な受け渡し用のため、大切なファイルは別途保存してください。

パスワード未設定の場合、URL を知っている人は内容にアクセスし、変更できます。閲覧やダウンロードだけを許可する場合は閲覧専用リンクを使い、パスワードは適切に管理してください。
