# Clipboard.im

### Isang link lang papunta sa susunod mong device.

Ang Clipboard.im ay isang magaan na online clipboard para maglipat ng text, mga link, at file sa pagitan ng mga device. Mag-paste sa computer, buksan sa telepono, o ibahagi sa iba — lahat sa browser, nang walang pagpaparehistro o pag-install ng app.

## Para sa maliliit na paglilipat araw-araw

- **Gamitin agad.** Walang kailangang account, login, app, o browser extension.
- **Isang address, maraming device.** Buksan ang parehong address sa telepono, tablet, o computer. Maaari mong palitan ang pangalan para madaling tandaan.
- **Magkasama ang text at mga file.** Mag-paste ng mga tala o link, mag-drag ng mga file, at kopyahin o i-download sa ibang device.
- **I-scan at magpatuloy.** Buksan sa telepono gamit ang QR code nang hindi tina-type ang address.
- **Piliin ang paraan ng pagbabahagi.** Magtakda ng password o gumawa ng read-only link para makabasa at makapag-download ang iba nang hindi nakakapag-edit o nakakapagbura. Maaaring lagyan ng hiwalay na password ang link at ihinto ang pagbabahagi.
- **Bagay sa paggamit mo.** Layout para sa mobile at desktop, maliwanag at madilim na tema, at interface sa 22 wika.

## Kailan ito kapaki-pakinabang

Maglipat ng link mula sa telepono papunta sa laptop. Magpadala ng dokumento sa pinagsasaluhang computer para i-print. Ibahagi ang mga tala sa pulong at attachment sa katrabaho gamit ang read-only link.

## Magsimula sa tatlong hakbang

1. Buksan ang website para makakuha ng clipboard address.
2. Mag-paste ng text o mag-upload ng mga file. Mag-click sa labas ng text field para i-save ang mga pagbabago.
3. Buksan ang parehong address sa ibang device o i-scan ang QR code. Kopyahin ang text o i-download ang mga file.

## Mga limitasyon at access

Sa kasalukuyan, nakasaad sa site ang **100 MB bawat file**, **300 MB bawat clipboard**, at awtomatikong paglilinis ng mga file pagkalipas ng **7 araw**. Tingnan ang upload area para sa pinakabagong limitasyon. Magtago ng hiwalay na kopya ng mahahalagang file; para ito sa pansamantalang paglilipat.

Kung walang password, maaaring buksan at baguhin ng sinumang nakakaalam ng address ang nilalaman. Gumamit ng read-only link kung pagtingin at pag-download lang ang kailangan. Panatilihing pribado ang password.
