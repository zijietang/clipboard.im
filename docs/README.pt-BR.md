# Clipboard.im

### Seu próximo dispositivo está a um link de distância.

Clipboard.im é uma área de transferência online leve para passar textos, links e arquivos entre dispositivos. Cole no computador, abra no celular ou compartilhe com outra pessoa — tudo pelo navegador, sem cadastro nem instalação de aplicativo.

## Para as pequenas transferências do dia a dia

- **Comece na hora.** Sem conta, login, aplicativo ou extensão de navegador.
- **Um endereço, vários dispositivos.** Abra o mesmo link no celular, tablet ou computador. Personalize o endereço para ficar mais fácil de lembrar.
- **Textos e arquivos juntos.** Cole notas ou links, arraste arquivos e copie ou baixe em outro dispositivo.
- **Escaneie e continue.** Abra no celular usando o QR code da página.
- **Escolha como compartilhar.** Defina uma senha ou crie um link somente leitura para visualizar e baixar sem editar ou excluir. O link pode ter uma senha própria e ser revogado.
- **Do seu jeito.** Layout responsivo, temas claro e escuro e interface em 22 idiomas.

## Quando usar

Passar um link do celular para o notebook. Levar um documento a um computador compartilhado para imprimir. Compartilhar notas de reunião e anexos com um colega por um link somente leitura.

## Comece em três passos

1. Abra o site para receber um endereço de área de transferência.
2. Cole um texto ou envie arquivos. Clique fora do campo de texto para salvar as alterações.
3. Abra o mesmo endereço em outro dispositivo ou escaneie o QR code. Copie o texto ou baixe os arquivos.

## Limites e acesso

O site informa atualmente **100 MB por arquivo**, **300 MB por área de transferência** e limpeza automática após **7 dias**. Confira os limites atuais na área de envio. Guarde uma cópia dos arquivos importantes: a ferramenta serve para transferências temporárias.

Sem senha, qualquer pessoa que conheça o endereço pode acessar e alterar o conteúdo. Use um link somente leitura para permitir apenas visualização e download. A senha controla o acesso; mantenha-a privada.
