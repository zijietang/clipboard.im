# Clipboard.im

### Zum nächsten Gerät reicht ein Link.

Clipboard.im ist eine schlanke Online-Zwischenablage für Texte, Links und Dateien zwischen Geräten. Am Computer einfügen, auf dem Handy öffnen oder mit anderen teilen — direkt im Browser, ohne Registrierung oder App-Installation.

## Für die kleinen Übertragungen im Alltag

- **Sofort loslegen.** Kein Konto, keine Anmeldung, App oder Browser-Erweiterung nötig.
- **Ein Link, mehrere Geräte.** Dieselbe Adresse auf Handy, Tablet oder Computer öffnen. Auf Wunsch lässt sich ein einprägsamer Name wählen.
- **Text und Dateien zusammen.** Notizen und Links einfügen, Dateien hineinziehen und auf einem anderen Gerät kopieren oder herunterladen.
- **Scannen und weitermachen.** Der QR-Code öffnet die Zwischenablage auf dem Handy, ohne die Adresse einzutippen.
- **Passend teilen.** Ein Passwort setzen oder einen schreibgeschützten Link zum Lesen und Herunterladen erstellen. Empfänger können nichts bearbeiten oder löschen. Der Freigabelink kann ein eigenes Passwort erhalten und widerrufen werden.
- **Passt zu deinem Gerät.** Responsives Layout, helles und dunkles Design sowie 22 Oberflächensprachen.

## Wann es praktisch ist

Einen Link vom Handy auf den Laptop übertragen. Ein Dokument zum Drucken an einen gemeinsam genutzten Computer schicken. Besprechungsnotizen und Anhänge über einen schreibgeschützten Link teilen.

## In drei Schritten starten

1. Die Website öffnen und eine Adresse für die Zwischenablage erhalten.
2. Text einfügen oder Dateien hochladen. Zum Speichern der Textänderungen außerhalb des Textfelds klicken.
3. Dieselbe Adresse auf einem anderen Gerät öffnen oder den QR-Code scannen. Text kopieren oder Dateien herunterladen.

## Grenzen und Zugriff

Die Website nennt derzeit **100 MB pro Datei**, **300 MB pro Zwischenablage** und automatische Dateibereinigung nach **7 Tagen**. Aktuelle Grenzen stehen im Upload-Bereich. Wichtige Dateien separat aufbewahren: Das Werkzeug ist für vorübergehende Übertragungen gedacht.

Ohne Passwort kann jeder, der die Adresse kennt, auf die Inhalte zugreifen und sie ändern. Für reines Lesen und Herunterladen einen schreibgeschützten Link verwenden. Passwörter steuern den Zugriff und sollten vertraulich bleiben.
