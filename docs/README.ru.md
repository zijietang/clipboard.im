# Clipboard.im

### До другого устройства — всего одна ссылка.

Clipboard.im — лёгкий онлайн-буфер обмена для передачи текста, ссылок и файлов между устройствами. Вставьте на компьютере, откройте на телефоне или поделитесь с другим человеком. Всё работает в браузере, без регистрации и установки приложения.

## Для небольших передач в течение дня

- **Начните сразу.** Не нужны аккаунт, вход, приложение или расширение браузера.
- **Один адрес для разных устройств.** Откройте его на телефоне, планшете или компьютере. Адрес можно сделать более запоминающимся.
- **Текст и файлы вместе.** Вставляйте заметки и ссылки, перетаскивайте файлы, затем копируйте или скачивайте на другом устройстве.
- **Откройте по QR-коду.** Сканируйте код телефоном вместо ручного ввода адреса.
- **Выберите способ доступа.** Установите пароль или создайте ссылку только для чтения: получатели смогут читать и скачивать, но не менять или удалять содержимое. Для ссылки можно задать отдельный пароль и отменить доступ.
- **Удобный интерфейс.** Адаптивная вёрстка, светлая и тёмная темы, 22 языка.

## Когда пригодится

Перенести ссылку с телефона на ноутбук. Отправить документ на общий компьютер для печати. Поделиться заметками со встречи и файлами с коллегой по ссылке только для чтения.

## Три шага для начала

1. Откройте сайт и получите адрес буфера обмена.
2. Вставьте текст или загрузите файлы. Нажмите вне текстового поля, чтобы сохранить изменения.
3. Откройте тот же адрес на другом устройстве или сканируйте QR-код. Скопируйте текст или скачайте файлы.

## Ограничения и доступ

Сейчас сайт указывает **100 МБ на файл**, **300 МБ на буфер обмена** и автоматическую очистку файлов через **7 дней**. Актуальные ограничения смотрите в области загрузки. Сохраняйте важные файлы отдельно: сервис предназначен для временной передачи.

Без пароля любой, кто знает адрес, может открывать и изменять содержимое. Для просмотра и скачивания используйте ссылку только для чтения. Пароль ограничивает доступ; не раскрывайте его посторонним.
