# Clipboard.im

### 換一台裝置，一個連結就夠了。

Clipboard.im 是輕巧的線上剪貼簿，讓你在手機、電腦與平板之間傳遞文字、連結和檔案。電腦上貼上，手機上開啟；既能暫時中轉，也能分享給別人。開啟瀏覽器就能用，無須註冊、登入或安裝應用程式。

## 讓臨時傳送更輕鬆

- **開啟即用。** 不需要帳號、登入、App 或瀏覽器擴充功能。
- **同一網址，跨裝置存取。** 在另一台裝置開啟相同網址，也可自訂容易記住的剪貼簿名稱。
- **文字與檔案集中管理。** 貼上筆記或連結、拖入檔案，再到另一台裝置複製或下載。
- **掃碼接著用。** 用手機掃描內建 QR Code，省去輸入網址。
- **自行選擇分享方式。** 設定剪貼簿密碼，或建立唯讀連結，讓對方查看文字、下載檔案而無法編輯或刪除。唯讀連結可另設密碼，也可停止分享。
- **適應你的使用習慣。** 支援行動與桌面版面、淺色與深色主題，以及 22 種介面語言。

## 適合哪些情境

將手機上的連結傳到電腦；到影印店臨時傳送文件；用唯讀連結與同事分享會議筆記和附件。

## 三步開始使用

1. 開啟網站，取得剪貼簿網址。
2. 貼上文字或上傳檔案；編輯文字後，點選輸入框外部儲存。
3. 在另一台裝置開啟同一網址，或掃描 QR Code，即可複製文字、下載檔案。

## 容量、保留期限與存取方式

網站目前標示：**每個檔案 100 MB**、**每個剪貼簿合計 300 MB**，檔案於 **7 天後自動清理**。最新限制以頁面上傳區為準。適合暫時中轉，重要檔案請另行備份。

未設定剪貼簿密碼時，知道網址的人可以存取並修改內容。只需讓他人查看或下載時，請使用唯讀連結。密碼用於控制存取，請妥善保管。
