# Clipboard.im

### Il prossimo dispositivo è a un link di distanza.

Clipboard.im è uno strumento leggero per gli appunti online che permette di trasferire testi, link e file tra dispositivi. Incolla sul computer, apri sul telefono o condividi con qualcuno: tutto dal browser, senza registrazione né app da installare.

## Per i piccoli trasferimenti di ogni giorno

- **Inizia subito.** Nessun account, accesso, applicazione o estensione necessaria.
- **Un indirizzo, più dispositivi.** Apri lo stesso link su telefono, tablet o computer. Personalizzalo per ricordarlo facilmente.
- **Testi e file insieme.** Incolla note o link, trascina file e copiali o scaricali su un altro dispositivo.
- **Scansiona e continua.** Apri gli appunti sul telefono con il codice QR, senza digitare l’indirizzo.
- **Scegli come condividere.** Imposta una password o crea un link di sola lettura per visualizzare e scaricare senza modificare o eliminare. Il link può avere una password separata ed essere revocato.
- **Come preferisci.** Layout adattivo, temi chiaro e scuro e interfaccia in 22 lingue.

## Quando è utile

Passare un link dal telefono al portatile. Inviare un documento a un computer condiviso per stamparlo. Condividere appunti di una riunione e allegati con un collega tramite un link di sola lettura.

## Inizia in tre passaggi

1. Apri il sito per ottenere un indirizzo per gli appunti.
2. Incolla testo o carica file. Fai clic fuori dal campo di testo per salvare le modifiche.
3. Apri lo stesso indirizzo su un altro dispositivo o scansiona il codice QR. Copia il testo o scarica i file.

## Limiti e accesso

Il sito indica attualmente **100 MB per file**, **300 MB per spazio appunti** e pulizia automatica dei file dopo **7 giorni**. Controlla l’area di caricamento per i limiti aggiornati. Conserva una copia dei file importanti: lo strumento serve per trasferimenti temporanei.

Senza password, chi conosce l’indirizzo può accedere ai contenuti e modificarli. Usa un link di sola lettura per consentire solo visualizzazione e download. Mantieni riservata la password di accesso.
