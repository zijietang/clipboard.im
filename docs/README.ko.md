# Clipboard.im

### 다음 기기까지, 링크 하나면 충분합니다.

Clipboard.im은 기기 사이에서 텍스트, 링크, 파일을 옮기는 가벼운 온라인 클립보드입니다. 컴퓨터에서 붙여 넣고 휴대폰에서 열어 보세요. 잠깐 파일을 옮기거나 다른 사람과 공유할 때도 브라우저만 있으면 됩니다. 회원 가입, 로그인, 앱 설치가 필요 없습니다.

## 간단한 전송을 더 간편하게

- **바로 시작하세요.** 계정, 로그인, 앱, 브라우저 확장 프로그램이 필요 없습니다.
- **주소 하나로 여러 기기에서.** 휴대폰, 태블릿, 컴퓨터에서 같은 주소를 여세요. 기억하기 쉬운 이름으로 바꿀 수도 있습니다.
- **텍스트와 파일을 한곳에.** 메모나 링크를 붙여 넣고 파일을 끌어다 놓은 뒤 다른 기기에서 복사하거나 다운로드하세요.
- **QR 코드로 열기.** 휴대폰으로 스캔하면 주소를 입력할 필요가 없습니다.
- **공유 방식 선택.** 클립보드 비밀번호를 설정하거나 읽기 전용 링크를 만드세요. 받는 사람은 수정·삭제 없이 확인하고 다운로드할 수 있습니다. 공유 링크에 별도 비밀번호를 설정하거나 공유를 중단할 수도 있습니다.
- **익숙한 환경에서.** 모바일·데스크톱 화면, 밝은·어두운 테마, 22개 언어를 지원합니다.

## 이럴 때 유용합니다

휴대폰의 링크를 노트북으로 옮길 때, 공용 컴퓨터에서 문서를 인쇄할 때, 회의 메모와 첨부 파일을 동료에게 읽기 전용으로 공유할 때.

## 세 단계로 시작하기

1. 웹사이트를 열어 클립보드 주소를 받으세요.
2. 텍스트를 붙여 넣거나 파일을 업로드하세요. 텍스트를 수정한 뒤 입력란 바깥을 클릭하면 저장됩니다.
3. 다른 기기에서 같은 주소를 열거나 QR 코드를 스캔하고, 텍스트를 복사하거나 파일을 다운로드하세요.

## 용량, 보관 기간, 접근 설정

현재 웹사이트 안내는 **파일당 100 MB**, **클립보드당 총 300 MB**, **7일 후 파일 자동 정리**입니다. 최신 제한은 업로드 영역을 확인하세요. 임시 전송용이므로 중요한 파일은 별도로 보관하세요.

비밀번호가 없으면 주소를 아는 사람이 내용을 확인하고 변경할 수 있습니다. 보기와 다운로드만 허용하려면 읽기 전용 링크를 사용하세요. 접근을 제어하는 비밀번호는 안전하게 보관하세요.
