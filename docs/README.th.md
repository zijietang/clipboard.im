# Clipboard.im

### ไปยังอีกอุปกรณ์ได้ด้วยลิงก์เดียว

Clipboard.im คือคลิปบอร์ดออนไลน์ขนาดเล็กสำหรับส่งข้อความ ลิงก์ และไฟล์ระหว่างอุปกรณ์ วางบนคอมพิวเตอร์แล้วเปิดบนมือถือ หรือแชร์ให้คนอื่นได้ผ่านเบราว์เซอร์ โดยไม่ต้องสมัครสมาชิกหรือติดตั้งแอป

## สำหรับการส่งข้อมูลเล็ก ๆ ในแต่ละวัน

- **เริ่มใช้ได้ทันที** ไม่ต้องมีบัญชี เข้าสู่ระบบ ติดตั้งแอป หรือส่วนขยายเบราว์เซอร์
- **ที่อยู่เดียว หลายอุปกรณ์** เปิดที่อยู่เดียวกันบนมือถือ แท็บเล็ต หรือคอมพิวเตอร์ และตั้งชื่อให้จำง่ายได้
- **ข้อความและไฟล์ในที่เดียว** วางโน้ตหรือลิงก์ ลากไฟล์มาวาง แล้วคัดลอกหรือดาวน์โหลดบนอีกอุปกรณ์
- **สแกนแล้วใช้ต่อ** เปิดคลิปบอร์ดบนมือถือด้วย QR code โดยไม่ต้องพิมพ์ที่อยู่
- **เลือกวิธีแชร์ได้** ตั้งรหัสผ่านให้คลิปบอร์ด หรือสร้างลิงก์แบบอ่านอย่างเดียวเพื่อให้ผู้รับดูและดาวน์โหลดโดยแก้ไขหรือลบไม่ได้ ลิงก์แชร์ตั้งรหัสผ่านแยกและยกเลิกได้
- **เข้ากับการใช้งานของคุณ** รองรับหน้าจอมือถือและคอมพิวเตอร์ ธีมสว่างและมืด และอินเทอร์เฟซ 22 ภาษา

## ใช้เมื่อไหร่ดี

ส่งลิงก์จากมือถือไปยังแล็ปท็อป ส่งเอกสารไปยังคอมพิวเตอร์ส่วนกลางเพื่อพิมพ์ หรือแชร์บันทึกประชุมและไฟล์แนบให้เพื่อนร่วมงานผ่านลิงก์แบบอ่านอย่างเดียว

## เริ่มใช้งานในสามขั้นตอน

1. เปิดเว็บไซต์เพื่อรับที่อยู่คลิปบอร์ด
2. วางข้อความหรืออัปโหลดไฟล์ คลิกนอกช่องข้อความเพื่อบันทึกการแก้ไข
3. เปิดที่อยู่เดียวกันบนอีกอุปกรณ์หรือสแกน QR code แล้วคัดลอกข้อความหรือดาวน์โหลดไฟล์

## ดูหน้าจอจริง

ภาพจากเว็บไซต์จริงโดยใช้เนื้อหาตัวอย่าง ถ่ายเมื่อ 18 ตุลาคม 2026 ภาพมือถือใช้ขนาดหน้าต่างเบราว์เซอร์แบบมือถือ อินเทอร์เฟซในภาพเป็นภาษาอังกฤษ

## ขีดจำกัดและการเข้าถึง

ขณะนี้เว็บไซต์ระบุ **100 MB ต่อไฟล์**, **300 MB ต่อคลิปบอร์ด** และล้างไฟล์อัตโนมัติหลัง **7 วัน** ตรวจสอบขีดจำกัดล่าสุดในส่วนอัปโหลด โปรดเก็บสำเนาไฟล์สำคัญไว้ต่างหาก เพราะเครื่องมือนี้ใช้ส่งข้อมูลชั่วคราว

หากไม่ตั้งรหัสผ่าน ผู้ที่ทราบที่อยู่จะเข้าถึงและเปลี่ยนเนื้อหาได้ ใช้ลิงก์แบบอ่านอย่างเดียวเมื่อให้ผู้อื่นดูหรือดาวน์โหลดเท่านั้น และเก็บรหัสผ่านเป็นความลับ
